# poster_6dof — Result Artifacts (SAE → Top-K → KF)

This folder contains **small, shareable artifacts** generated by the pipeline for quick review.

## Run configuration (key)
- Tracker: Kalman Filter (Top-K driven)
- gate: 45 px (see filenames `*_gate45*`)
- Outputs include candidate metrics, tracking metrics, plots, and a trajectory CSV.

## Files
### Demo
- `demo_kf_gate45.mp4` : tracking overlay demo

### Structured outputs
- `trajectory_kf_gate45.csv` : final KF trajectory (time/frame + x/y + optional score)
- `metrics_stage2_topk.json` : Stage2 candidate stats
- `metrics_stage3_tracking_gate45.json` : Stage3 tracking metrics

### Plots (what they mean)
- `plot_topk_hist.png` : distribution of candidate scores/Top-K stats
- `plot_topk_timeseries.png` : Top-K signal over time (stability / drift)
- `plot_bestscore_hist.png` : best-score histogram (confidence profile)
- `plot_tracklen_hist_gate45.png` : track length distribution (continuity)
- `plot_innovation_hist_gate45.png` : innovation histogram (KF residual; stability indicator)
- `plot_by_speed_gate45.png` : metrics stratified by speed buckets (robustness under fast motion)

## How to interpret (quick)
- Lower innovation / tighter distribution → more stable tracking
- Longer track length → fewer breaks / better continuity
- Speed-bucket plot shows performance degradation as speed increases (expected trend)
